# Human Navigation System — AI App Development Prompt

Build a modern, interactive **human-centric city navigation web/mobile application** called **Human Navigation System**.

The core concept is:

> **“It’s not just about finding the fastest way; it’s about finding the right way for you.”**

Unlike conventional navigation apps that optimize mainly for distance or travel time, this application should recommend routes based on **human experience**, including mood, comfort, quietness, shade, crowd levels, personal memories, frequently visited places, community experiences, and meaningful locations.

The visual experience should be inspired by the **exploration feel of Pokémon GO's map**, but DO NOT use Pokémon, Eevee, copyrighted characters, or Pokémon branding. Create an original visual identity.

---

## 1. HOME / AR CITY MAP

The main screen should be a highly visual **3D/AR-inspired city map**.

Show:

* Roads and intersections
* Buildings
* Parks
* Trees
* Water bodies
* Public spaces
* Cafés
* Libraries
* Bookstores
* Temples
* Art spaces
* Markets
* Frequently visited places
* Community locations
* Personal memory locations

Use floating location markers over the map.

Each marker should communicate the type of experience:

* 🌳 Green = Nature / shaded
* 🤫 Blue = Quiet
* ❤️ Pink = Memory
* 👥 Orange/Pink = Community
* ☕ Yellow = Café / social
* 📚 Blue = Learning
* 🎨 Purple = Art / culture
* 🛡️ Safety/comfort
* 📸 Scenic location

Do not make the interface look like a normal Google Maps clone.

The map should feel like an **interactive living city**.

---

## 2. USER AVATAR

Remove all gaming-level systems.

There should be **no XP, levels, coins, battles, raids, Pokémon, or game progression**.

Instead, show a simple customizable **human avatar** representing the user.

The avatar should appear on the map at the user's current location.

Allow users to customize:

* Hair
* Clothing
* Backpack
* Accessories
* Walking/cycling preference

Keep the avatar friendly and minimal.

---

## 4. PERSONALIZED ROUTE SYSTEM

The most important feature is **Human-Centric Route Recommendation**.

When the user enters a destination, do not immediately show only the fastest route.

Ask:

### “How do you want to travel today?”

Provide selectable preferences:

* 🤫 Quiet
* 🌳 Shaded
* 🛡️ Comfortable
* 👥 Social
* ❤️ Memory
* 🌅 Scenic
* 🚶 Relaxed
* ⚡ Fast
* ✨ Custom

The user can select one or multiple preferences.

Example:

User selects:

**Quiet + Shaded + Scenic**

The application should generate a route optimized around these preferences.

Show:

**Recommended Human Route**

> 22 min · 1.8 km
> Slightly longer than the fastest route
> 70% quieter
> More shaded paths
> 2 scenic locations

Also show the conventional fastest route for comparison.

## 6. MEMORY MAP

Create a dedicated **Memories** section.

Users can save memories to locations.

A memory can contain:

* Photo
* Short note
* Date
* Mood
* Location
* People/category tags

Example:

❤️ **First College Event**
“Spent the evening here with my friends.”

When navigating through the city, the application can optionally suggest:

> **“You're near a place connected to one of your memories.”**

Allow users to choose whether memories are private or shared with the community.

# TECHNICAL REQUIREMENTS

Build the application with a modular architecture.

### Frontend

Use:

* React
* TypeScript
* Tailwind CSS
* Responsive mobile-first UI
* Framer Motion for animations

### Maps

Use a map provider such as:

* Mapbox
* OpenStreetMap
* Leaflet

Create a custom map style with interactive markers.

### Backend

Use:

* FastAPI or Node.js
* REST APIs
* PostgreSQL

### Authentication

Support:

* Email/password
* Google authentication

### Database

Store:

* Users
* Avatars
* Places
* Routes
* Memories
* Community contributions
* User preferences
* Mood selections
* Frequently visited locations

### Recommendation Engine

Create a route scoring system.

Example:

Human Route Score =

**Quietness + Shade + Comfort + Scenic Value + Memory Relevance + Community Preference**

Allow the weights to change depending on the user's selected preferences.

# MOST IMPORTANT PRODUCT PRINCIPLE

The application should demonstrate that:

### Traditional Navigation

**Destination → Fastest Route**

### Human Navigation

**Person → Mood → Needs → Memories → Community → Environment → Destination → Personalized Route**

Make this distinction visually obvious throughout the application.

The final product should feel like a **living map of human experiences**, where the city is not just a collection of roads but a collection of places, memories, emotions, and stories.
